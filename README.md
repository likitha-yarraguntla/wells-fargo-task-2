# Wells Fargo Software Development Job Simulation - Task 2

## 📌 Project Overview
This repository contains my implementation for **Task 2 (Implement a Data Model)** of the Wells Fargo Software Development program on Forage. The objective is to build a structured data model using Java Persistence API (JPA) to model relationships effectively.

---

## 🛠️ Tech Stack & Concepts Used
* **Backend Language:** Java 17 / Object-Oriented Programming (OOPs)
* **Framework:** Spring Boot & Spring Data JPA
* **Database Management:** Hibernate (ORM), H2/MySQL
* **Build Tool:** Maven
* **Version Control:** Git & GitHub

---

## 🚀 Key Learning Outcomes
* **JPA Annotations:** Learned how to map Java classes to database tables using `@Entity`, `@Table`, `@Id`, and `@GeneratedValue`.
* **Data Modeling:** Modeled real-world relationships like One-to-Many (`@OneToMany`) and Many-to-One (`@ManyToOne`) between entities.
* **Clean Code Practices:** Maintained enterprise-level coding standards as expected in Wells Fargo workflows.

---

## 📂 Project Structure
* `src/main/java/com/wellsfargo/counselor` - Contains the main source code, entity classes, and data models.
* `pom.xml` - Project dependencies management.
